# اقساط من — نسخه آماده انتشار روی GitHub Pages

## انتشار
1. یک Repository جدید در GitHub بسازید (ترجیحاً Public).
2. محتویات این پوشه را در ریشه Repository آپلود کنید؛ یعنی `index.html` باید در ریشه باشد، نه داخل یک پوشه دیگر.
3. وارد Settings → Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/(root)` قرار دهید و Save کنید.
6. پس از پایان انتشار، آدرس شبیه `https://USERNAME.github.io/REPOSITORY/` در همان صفحه نمایش داده می‌شود.

## نصب
- Android: لینک را با Chrome باز کنید و از منوی مرورگر Install app یا Add to Home screen را بزنید.
- iPhone: لینک را با Safari باز کنید، Share و سپس Add to Home Screen را انتخاب کنید.

## نکته درباره داده‌ها
اطلاعات اقساط در حافظه محلی همان مرورگر/دستگاه ذخیره می‌شود. پاک کردن داده‌های مرورگر ممکن است آن‌ها را حذف کند؛ از بخش تنظیمات برنامه مرتباً پشتیبان بگیرید. برای انتقال داده بین دستگاه‌ها باید بعداً همگام‌سازی ابری اضافه شود.
